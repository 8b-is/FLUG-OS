FLUG-OS {-1, 0, +1}

Fluid Operating System for the Flipper Zero WiFi Module v1
802.11 Packet-Wave Sampler · RSSI → Amplitude · Frame Type → Frequency

ESP8285 Flipper Zero {-1, 0, +1} promiscuous mode

What it does

Turns your Flipper Zero WiFi Module into a raw 802.11 wave sampler. Every WiFi packet becomes a musical note. RSSI becomes amplitude. Frame type determines frequency. Packet density drives rhythm.

Piped into music.vaked.dev, the ambient WiFi spectrum becomes generative music — the invisible made audible.

Wave output modes

mode raw   → "0.750 0.320 0"     RSSI density type
mode wave  → "0.4231"             synthesized sinusoid
mode json  → {"rssi","freq"...}  structured musical JSON

Commands

ch 6           Set channel 1-13
hop           Channel hopping
mode raw|wave|json  Wave output mode
filter mgmt|data|ctrl|all  Frame type filter
stats         Capture statistics
reset         Reset counters

Flash it

git clone https://github.com/8b-is/FLUG-OS.git
cd FLUG-OS
pio run -e esp8285 -t upload

Listen

python3 bridge/wave_bridge.py /dev/tty.usbserial-XXXX \
  --mode wave --dump | play -t raw -r 44100 -e float -b 32 -
